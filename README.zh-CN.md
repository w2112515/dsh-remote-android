# DSH Remote Android

[DSH Remote Host](https://github.com/w2112515/dsh-remote-host) 的手机客户端。

先在电脑上安装 Host 插件（或 [DSH Remote 整合包](https://github.com/w2112515/dsh-remote-pack)），再从 [Releases](https://github.com/w2112515/dsh-remote-android/releases) 下载 **一个 APK**。市场整合包装不了这个应用。

## 使用

1. 电脑：`dsh plugin --profile web add @w2112515/dsh-remote-host`，重启 `dsh web`，打开「设置 → 手机访问」，打开附近发现。
2. 手机安装 APK。
3. 连同一 Wi-Fi，扫 Host 二维码，在电脑上确认八位比较码。

本仓库是 Android 应用，不是 DSH 插件。
